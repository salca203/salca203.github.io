# Meine Website

Das ist meine persönliche Website mit verschiedenen Modulen und Funktionen.

## Funktionen

- Live Datum und Uhrzeit
- Darkmode Umschalter
- Klickzähler
- Mini Spiel
- Kontaktformular
- Impressum
- Mobile freundliches Design
- Speicherung von Einstellungen im Browser

## Live Website

Die Website ist hier erreichbar:

https://DEINUSERNAME.github.io/meine-website

Ersetze DEINUSERNAME mit deinem GitHub Namen.

## Installation

1. Repository herunterladen oder klonen
2. index.html im Browser öffnen

Oder direkt über GitHub Pages nutzen.

## Technologien

- HTML
- CSS
- JavaScript
- GitHub Pages Hosting

## Erweiterung

Die Website ist modular aufgebaut und kann leicht erweitert werden mit:

- weiteren Spielen
- Kalender Modulen
- Tools
- Widgets
- Design Erweiterungen
